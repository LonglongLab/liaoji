# 聊记 · 远程端

存储、检索、浏览和分享由本地端同步的已解析聊天档案，提供自托管 Python 服务与 Cloudflare Workers 两种运行时。

本仓库不含本地采集、微信数据库解密、进程密钥提取或原始媒体解密实现，也不含个人配置、真实聊天数据及原项目 Git 历史。
共享协议可能保留本地能力名称或历史状态枚举，它们不提供本地执行能力。登录、备份及对象存储凭据保护所需的通用加密继续保留。

构建和自托管部署见 [BUILD.md](BUILD.md)。所有域名、账号、资源 ID 与凭据均需自行配置。
本仓库公开可见，第一方源码仍适用 [SOURCE-LICENSE.txt](SOURCE-LICENSE.txt)；未另行选择 OSI 开源许可证。
